# Análise de Vendas de Velas

Trabalho de conclusão de curso (TCC) do curso de Tecnologia em Banco de Dados. O sistema lê as planilhas de vendas exportadas do PDV de uma fábrica de velas e gera análises de faturamento por mês, desempenho dos produtos e a relação entre os picos de venda e datas comemorativas e religiosas, como Páscoa e Dia das Mães.

Feito com Python, Streamlit, SQLAlchemy e banco de dados PostgreSQL (Supabase).
